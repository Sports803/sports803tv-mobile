# Sports803TV Blogger App Companion Theme

Import `Sports803TV-app-companion.xml` in **Blogger → Theme → Restore**. The theme retains the existing Sports803 template and adds a responsive Sports803TV Android-install panel directly below the site header.

## Set the real APK download link

After an Android APK has been published, open **Blogger → Layout → Sports803TV App Install → Edit**. Replace the current link in the `href` attribute of the **Get the Android app** button with the direct HTTPS APK download URL. Until then, the button intentionally opens the Sports803TV GitHub Releases page instead of claiming an APK is available.

## Widget behavior

The install panel is a full-width desktop card with a compact, full-width call-to-action on small screens. It does not use pop-ups, forced redirects, or third-party scripts. The existing Blogger widgets and page content remain unchanged.
